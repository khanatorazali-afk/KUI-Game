# KÜI — Python прототипі (v0.1)

Windows: Python орнатыңыз. Осы папкада терминал ашып:
```
python -m pip install -r requirements.txt
python main.py
```
7 күйдің атауы, 4 жолақ, 40 нота, үш қиындық, жергілікті рекорд, дыбыс баптауы. Нота дыбыстары синтетикалық, күйлердің нақты әуені емес. Күйге сәйкес лицензияланған жазба/нота картасы кейін қосылуы керек. Орташа деңгей ғана сервер рейтингіне жіберіледі (жергілікті рекорд барлық деңгей бойынша).

## Онлайн сынақ
Бөлек терминалда `python server.py` іске қосыңыз. Профиль және баптаулар мәзіріне бір компьютерде `http://127.0.0.1:8080` енгізіңіз. Екінші құрылғыға жергілікті желідегі сервер IP-адресін енгізіңіз. Екі ойыншыға бөлек ат қойыңыз. Онлайн дуэль бір күйді таңдаған екі ойыншыны қосады; дос бөлмесі код арқылы жұмыс істейді (әзірге Адай). HTTP Android жүйесінде шектелуі мүмкін; жария серверге HTTPS қажет. Бұл тест сервері: аккаунт аутентификациясы, сенімді античит, қауіпсіз рейтинг, нақты синхрондау және тұрақты интернет хостинг әлі жоқ. Пайдаланушы атын қайталап қою мүмкін. SQLite деректері серверде сақталады.

## Android APK/AAB
Linux/WSL ортасында Buildozer және оның Android құралдарын орнатып, осы папкада `buildozer android debug` орындаңыз. APK `bin/` ішіне түседі. Release AAB үшін `buildozer android release`, қол қою, Google Play талаптарын тексеру керек. Бұл жинақта APK/AAB жоқ; құрылғыда сыналмаған. Kivy бұл ортада орнатылмаған, сондықтан интерфейс іске қосылып тексерілген жоқ.
